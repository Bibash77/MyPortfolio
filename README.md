# Bibash Bogati — Backend-Engineer Portfolio

Static portfolio built with plain HTML, CSS and JavaScript.

## Highlights

- Personal hero with profile photo
- Experience-first vertical career timeline
- Rich skill/tool section with technology icons
- Searchable project section
- Project filters by Professional / Client / Personal / POC
- Projects ordered by complexity and engineering scope
- Backend-engineering visual language
- Responsive mobile layout

## Files

- `index.html`
- `styles.css`
- `script.js`
- `assets/profile.jpg`

## Local preview

```bash
python3 -m http.server 8080
```

Then visit:

```text
http://localhost:8080
```

## Hosting

Deploy directly to GitHub Pages, Vercel, Netlify, Cloudflare Pages, AWS S3 + CloudFront, or any static web server.
